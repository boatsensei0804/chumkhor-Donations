# คู่มือการติดตั้งและใช้งานระบบแสดงยอดบริจาคผ้าป่าเพื่อการศึกษา
## โรงเรียนชำฆ้อพิทยาคม (Google Apps Script Edition)

ระบบแสดงยอดบริจาคผ้าป่าและนับถอยหลังแบบ **Serverless 100%** ทำงานบน **Google Workspace (Google Sheets + Google Apps Script)** ฟรีตลอดชีพ ไม่ต้องติดตั้ง Node.js, MongoDB, Docker หรือเช่าเซิร์ฟเวอร์ใดๆ

---

### 📁 ไฟล์ในโปรเจกต์
ในโฟลเดอร์ `google-apps-script/` ประกอบด้วย 3 ไฟล์หลัก:
1. **`Code.gs`** : รหัสฝั่งเซิร์ฟเวอร์ (Google Apps Script) ควบคุมการอ่าน-เขียนข้อมูลใน Google Sheets, คำนวณยอดเงิน, และจัดการเว็บแอป
2. **`Display.html`** : หน้าจอแสดงผลขนาดใหญ่สำหรับฉายขึ้นจอโปรเจกเตอร์/สมาร์ททีวี มีตัวเลขนับถอยหลังถึง 12:00 น. วันเสาร์ที่ ๓ ตุลาคม, กราฟิกสีมงคลน้ำเงิน-ทอง, พลุฉลอง, และแถบตัววิ่ง
3. **`Admin.html`** : หน้าจอแอดมินสำหรับคุณครูและทีมงาน มีระบบใส่รหัส PIN (ค่าเริ่มต้น `1234`), ฟอร์มบันทึกยอดแบบเรียลไทม์, ปุ่มบวกยอดด่วน, และเมนูแก้ไขการตั้งค่า

### 🚀 ขั้นตอนการติดตั้งใช้งาน (ใช้เวลาเพียง 3-5 นาที)

#### ขั้นตอนที่ 1: สร้าง Google Sheets ใหม่
1. เปิดเบราว์เซอร์ไปที่ [sheets.new](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ที่มุมซ้ายบน เช่น:
   ```text
   ระบบยอดบริจาคผ้าป่า ๒๕๖๙ - โรงเรียนชำฆ้อพิทยาคม
   ```

#### ขั้นตอนที่ 2: เปิดโปรแกรมแก้ไข Apps Script
1. ที่แถบเมนูด้านบนของ Google Sheets ให้คลิก:
   **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. ตั้งชื่อโครงการ Apps Script ที่มุมบนซ้าย เช่น `CKP Donation Display`

#### ขั้นตอนที่ 3: วางโค้ดลงใน 3 ไฟล์
1. **ไฟล์ `Code.gs`**:
   - ลบคลิกโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
   - คัดลอกเนื้อหาทั้งหมดจากไฟล์ [`Code.gs`](file:///Users/boat.suphaphit/Development/CKP-2026/google-apps-script/Code.gs) มาวางแทนที่
2. **ไฟล์ `Display.html`**:
   - คลิกที่เครื่องหมายบวก **`+`** ข้างข้อความ "ไฟล์" (Files) ➔ เลือก **HTML**
   - ตั้งชื่อไฟล์ว่า `Display` (ไม่ต้องใส่นามสกุล .html)
   - ลบคลิกโค้ดเริ่มต้นออก แล้วคัดลอกเนื้อหาจากไฟล์ [`Display.html`](file:///Users/boat.suphaphit/Development/CKP-2026/google-apps-script/Display.html) มาวาง
3. **ไฟล์ `Admin.html`**:
   - คลิกที่เครื่องหมายบวก **`+`** อีกครั้ง ➔ เลือก **HTML**
   - ตั้งชื่อไฟล์ว่า `Admin` (ไม่ต้องใส่นามสกุล .html)
   - ลบคลิกโค้ดเริ่มต้นออก แล้วคัดลอกเนื้อหาจากไฟล์ [`Admin.html`](file:///Users/boat.suphaphit/Development/CKP-2026/google-apps-script/Admin.html) มาวาง
4. กดปุ่มบันทึก (ไอคอนรูปแผ่นดิสก์ 💾 หรือกด `Ctrl + S` / `Cmd + S`)

#### ขั้นตอนที่ 4: สั่งสร้างแผ่นงานเริ่มต้น (Initial Setup)
1. ที่แถบเครื่องมือด้านบน ในช่องเลือกฟังก์ชัน สามารถเลือก **`myFunction`** หรือ **`initSheets`** ก็ได้ (ระบบได้เชื่อมโยงให้ทำงานเหมือนกัน)
2. คลิกปุ่ม **เรียกใช้ (Run ▶)**
3. จะมีหน้าต่างขอสิทธิ์การเข้าถึงปรากฏขึ้น (ครั้งแรกเท่านั้น):
   - คลิก **ตรวจสอบสิทธิ์ (Review permissions)**
   - เลือกบัญชี Google ของท่าน
   - หากขึ้นเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้คลิก **ขั้นสูง (Advanced)** ➔ คลิก **ไปที่ ... (ไม่ปลอดภัย) / Go to ... (unsafe)**
   - คลิก **อนุญาต (Allow)**
4. เมื่อรันเสร็จ ที่แถบด้านล่างจะขึ้นข้อความ `✅ ระบบสร้างแผ่นงานเริ่มต้น (Donations และ Settings) เรียบร้อยแล้ว`
   และใน Google Sheets จะพบ 2 แท็บชีตถูกสร้างและจัดรูปแบบให้อัตโนมัติ:
   - 📑 **`Donations`** (เก็บรายชื่อผู้บริจาค, จำนวนเงิน, เวลา, หมายเหตุ)
   - ⚙️ **`Settings`** (เก็บชื่องาน, เวลานับถอยหลัง, รหัส PIN, เสียง, ลิงก์พื้นหลัง)

#### ขั้นตอนที่ 5: นำไปใช้งาน (Deploy as Web App)
1. ที่มุมขวาบนของ Apps Script คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ➔ เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนฟันเฟือง ⚙️ ด้านซ้าย ➔ เลือก **เว็บแอป (Web app)**
3. กำหนดค่าดังนี้:
   - **คำอธิบาย (Description)**: `เวอร์ชัน 1.0`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (อีเมลของท่าน)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(สำคัญมาก เพื่อให้หน้าจอฉายและคุณครูเปิดได้โดยไม่ต้องเข้าสู่ระบบ Google ซ้ำซ้อน)*
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. ท่านจะได้รับลิงก์ **URL เว็บแอป (Web App URL)** เช่น:
   ```text
   https://script.google.com/macros/s/AKfycbx.../exec
   ```

### 🖥️ การเข้าใช้งานระบบ

นำ URL ที่ได้จากขั้นตอนที่ 5 ไปใช้งานดังนี้:

| หน้าจอ | ลิงก์ที่ใช้งาน | วัตถุประสงค์ |
| :--- | :--- | :--- |
| **หน้าจอฉาย (Display)** | `https://script.google.com/macros/s/.../exec` | ฉายขึ้นจอโปรเจกเตอร์ หรือเปิดบน Smart TV / คอมพิวเตอร์ |
| **หน้าจอจัดการ (Admin)** | `https://script.google.com/macros/s/.../exec?screen=admin` | ให้คุณครูบันทึกยอดบริจาคผ่านมือถือ แท็บเล็ต หรือคอมพิวเตอร์ |
| **Google Sheet โดยตรง** | เปิดผ่าน Google Drive | กรอกหรือแก้ไขยอดเป็นตารางได้โดยตรง |

> 🔑 **รหัส PIN เข้าหน้า Admin เริ่มต้น**: `1234`  
> *(สามารถเปลี่ยนได้ในการตั้งค่าหน้า Admin หรือในชีต Settings)*

### ✨ ฟังก์ชันและคุณสมบัติเด่น

1. **แสดงผลแบบเรียลไทม์ (Auto Polling)**:
   - หน้าจอ Display จะดึงข้อมูลล่าสุดจาก Google Sheets ทุกๆ 3.5 วินาทีโดยอัตโนมัติ
   - เมื่อมีการบันทึกยอดใหม่ จะมีป้าย Popup พิธีการเด้งขึ้นมากลางจอ พร้อมเสียงระฆังและพลุเฉลิมฉลอง
2. **นาฬิกานับถอยหลัง (Countdown Timer)**:
   - นับถอยหลังสู่ **เวลา 12:00 น. วันเสาร์ที่ ๓ ตุลาคม ๒๕๖๙**
   - สามารถเปิด-ปิด หรือเปลี่ยนเวลาเป้าหมายได้ผ่านหน้า Admin
3. **การทำงานร่วมกับ Google Sheets สองทาง**:
   - คุณครูสามารถพิมพ์ข้อมูลลงแถวใหม่ใน Sheet `Donations` ได้โดยตรง
   - หรือจะใช้หน้าเว็บแอดมินที่มีปุ่มบวกเงินด่วน (+100, +500, +1,000, +5,000, +10,000, +50,000) ก็สะดวกมาก
4. **โหมดกำหนดหรือทดทดแทนยอดรวม (Total Override)**:
   - หากช่วงนับยอดสดต้องการระบุตัวเลขรวมกลมๆ ทันที สามารถใส่ตัวเลขในช่อง Override ได้ และเมื่อเสร็จสิ้นก็กดคืนค่าเป็นผลรวมอัตโนมัติได้ทุกเมื่อ
5. **ความปลอดภัยและความเสถียร**:
   - ไม่ต้องกังวลเรื่องเซิร์ฟเวอร์ล่มหรือไฟดับ
   - ข้อมูลทุกรายการถูกบันทึกสำรองใน Google Cloud ตลอดเวลา
